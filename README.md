# Explorer Pro

Единое расширение VS Code вместо прототипов Explorer Pro и FocusedRoot. Навигатор каталогов и переключение корня рабочего пространства находятся в одном расширении и используют разные, явно названные действия.

## Как пользоваться

1. В секции Explorer откройте **Explorer Pro**. Кнопка выбора папки позволяет начать с любого локального каталога.
2. Один клик по файлу открывает preview; двойной клик или «Войти / Открыть» закрепляет вкладку. Папку можно раскрыть стрелкой, а двойным кликом или командой «Войти / Открыть» сделать корнем навигатора.
3. Кнопки «Назад», «Вперёд», «Вверх» и «В корень» перемещают только навигатор. Открытый проект остаётся прежним.
4. В контекстном меню папки выберите **Explorer Pro: Сделать папку корнем рабочего пространства**. Команда также есть в меню панели и во встроенном проводнике. VS Code откроет временное рабочее пространство в текущем окне, поэтому возможен перезапуск расширений и стандартный запрос доверия VS Code.
5. Нажмите индикатор **Фокус: project/backend/api** в строке состояния: меню предлагает **Назад**, **Полный проект**, **Выбрать другой фокус…**. Исходный сохранённый `.code-workspace` открывается целиком. «Предыдущий фокус рабочего пространства» возвращает к предыдущей папке; из первого фокуса — к исходному проекту.
6. **Сохранить домашнюю папку** запоминает выбранный каталог. **Перейти в домашнюю папку** открывает его в навигаторе; чтобы менять workspace, используйте отдельную команду фокуса.
7. **Открыть терминал здесь** использует выделенную папку навигатора; при выборе файла — его родительскую папку. Без выделения используется текущий каталог навигатора. Контекстное меню использует именно элемент, по которому вызвано меню. Автоматическое открытие терминалов по умолчанию выключено.

История навигатора сохраняется между сессиями. Недоступные папки в истории можно пропустить; недоступная домашняя папка выдаёт понятную ошибку. Фокус восстанавливается после перезапуска только для собственного временного workspace. Другие окна не подхватывают чужое состояние.

Значок карточки расширения — оригинальная синяя папка в рамке фокуса на тёмной скруглённой плашке, в современном стиле VS Code. PNG 256 × 256: `resources/extension-icon.png`; SVG-исходник рядом. Воспроизводимая генерация: `npm run icon` (без дополнительных зависимостей).

## Установка

Требуется VS Code 1.85 или новее; локально проверяется установленный VS Code на macOS. Скачайте `explorer-pro-0.4.2.vsix` из релиза: https://github.com/Multsev/vscode-explorer-pro/releases/tag/v0.4.2. В Extensions → «…» → Install from VSIX выберите скачанный файл. При локальной сборке пакет находится в `out/`.

```sh
code --install-extension out/explorer-pro-0.4.2.vsix --force
```

После установки, если панель ещё не появилась: **Developer: Reload Window**. Идентификатор расширения — `max-local.explorer-pro`. Если ранее установлены отдельные прототипы Explorer Pro или FocusedRoot, отключите их, чтобы не видеть несколько навигаторов. Их сохранённое состояние автоматически не переносится.

## Удаление и множественное выделение

Выделите файл или папку, затем выберите **Удалить выбранные элементы в корзину** в контекстном меню. На macOS можно нажать **Cmd+Backspace**, на Windows/Linux — **Delete**, когда фокус находится в списке Explorer Pro.

Для диапазона: нажмите первый элемент, затем **Shift+клик** по последнему. Для отдельных элементов: **Cmd+клик** на macOS или **Ctrl+клик** на Windows/Linux. Контекстное меню выделенного элемента удаляет всё выделение; если нажать правой кнопкой по элементу вне выделения, команда относится только к нему. Во время множественного выделения клики не открывают файлы и не переключают корень навигатора.

Перед удалением показываются количество и пути элементов. Папки отправляются в корзину вместе с содержимым; вложенные элементы уже выбранной папки не удаляются повторно. Отмена оставляет файлы на месте. Если имеются несохранённые открытые файлы внутри выбора, сначала сохраните или отмените изменения. Текущий корень навигатора и его родители защищены: для удаления такой папки сначала перейдите на уровень выше. Ошибка корзины сообщается пользователю; безвозвратное удаление вместо корзины не выполняется. Восстановление — через системную корзину.

## Настройки

Все настройки имеют префикс `extensionExplorer.`:

| Настройка | По умолчанию | Назначение |
|---|---|---|
| `startPath` | `null` | Первая папка workspace или домашний каталог; можно задать абсолютный или относительный путь |
| `showHidden` | `false` | Показывать имена, начинающиеся с точки |
| `sortMode` | `typeThenName` | Папки перед файлами; альтернативы `name`, `mtime` |
| `persistState` | `true` | Сохранять каталог и историю навигатора |
| `historyMaxLength` | `100` | Максимум записей истории навигатора |
| `doubleClickTimeoutMs` | `400` | Интервал двойного клика |
| `openFilesOnSingleClick` | `true` | Открывать файл по клику |
| `openFilesInPreview` | `true` | Открывать файл в preview |
| `enterFolderOnDoubleClick` | `true` | Заходить в папку двойным кликом |
| `openTerminalOnEnter` | `false` | Открывать терминал при переходах навигатора |
| `openTerminalOnFocus` | `false` | Открывать терминал после переключения workspace |
| `closePreviousTerminals` | `false` | Закрывать предыдущие терминалы, созданные этим расширением |

Клавиши при фокусе на списке навигатора: `Alt+← / Alt+→` (`Cmd+[ / Cmd+]` на macOS), Enter — открыть, Backspace — вверх. `Ctrl+Alt+F` (`Cmd+Alt+F`) возвращает к исходному проекту, когда включён фокус.

## Разработка

Нужен Node.js 22+ и npm. Для воспроизводимой установки используется lockfile:

```sh
npm ci
npm run compile
npm run lint
npm test
npm run test:host
npm run package
```

`npm run test:host` запускает **установленное приложение VS Code**, не загружая отдельную копию. По умолчанию используется `/Applications/Visual Studio Code.app/Contents/MacOS/Code`; другой исполняемый файл задайте переменной `VSCODE_EXECUTABLE`. Профиль и список расширений изолированы от рабочего окна. Тестовые файлы создаются в `.runtime/`, профиль — во временной папке. F5 запускает обычный Extension Development Host.

## Устройство проекта

- `src/extension.ts` — создание компонентов и регистрация lifecycle.
- `src/controller/` — команды и взаимодействие с навигатором.
- `src/tree/` — чтение каталогов и стандартный VS Code TreeView с файловыми значками текущей темы.
- `src/history/` — чистая логика истории навигатора.
- `src/focus/` — история фокуса, сохранение исходного workspace и адаптер VS Code.
- `src/services/terminalService.ts` — терминалы по каталогам, их повторное использование и очистка ссылок.
- `src/test/` — модульные тесты истории, кликов и восстановления фокуса.
- `src/hostTest/`, `scripts/run-host-tests.cjs` — проверки в реальном Extension Host.
- `resources/`, `package.nls*.json` — кнопки и русская/английская локализация.
- `docs/` — решения и результаты проверки; `out/` — сборка и VSIX.

Для новой команды добавьте обработчик в контроллер, регистрацию в `package.json` и переводы в оба `package.nls*.json`. Логику восстановления workspace изменяйте в `src/focus/` с тестами ошибок и повторного запуска.

## Ограничения и данные

Поддерживаются локальные каталоги desktop VS Code. Remote/виртуальные workspace пока не заявлены. Навигационные команды не перемещают файлы. Удаление — отдельная подтверждаемая команда, изменяющая содержимое выбранных папок.

Фокус создаёт служебный `.code-workspace` в глобальном хранилище расширения. В нём сохраняются исходные пути, имена корней и история фокуса. Сохранённый исходный workspace не перезаписывается. Очистка запускается при активации и вручную командой **Очистить старые служебные workspace**. Сохраняются 20 последних файлов, активные окна и рекурсивно связанные точки возврата; удаляются только остальные собственные файлы старше 30 дней. Активные окна отмечаются lease-файлами с PID Extension Host. Настройки уровня исходного workspace, задачи и launch-конфигурации не копируются в временный фокус; после возврата вновь используются исходные. Для несохранённого много-корневого workspace восстанавливаются корневые папки и имена; пустое окно возвращается к пустому workspace.

Если исходный проект недоступен, возврат предлагает найти папку или `.code-workspace` заново, открыть сохранившиеся корни либо выйти в пустой workspace. Отмена сохраняет текущий фокус и возможность повторить возврат.

Терминал доступен только в доверенном workspace. При выключении расширения пользовательские shell-процессы не закрываются. Текущая реализация обновляет содержимое текущего каталога автоматически; для изменений внутри раскрытых вложенных папок используйте «Обновить».

В исходниках: `docs/adr/0001-unified-navigation-and-focus.md` — история объединения, `docs/verification.md` — результаты проверки, `ROADMAP.md` — план, `task.json` — задачи, `CHANGELOG.md` — изменения.
