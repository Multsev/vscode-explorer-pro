# Changelog

## Unreleased

## 0.2.1 — 2026-10-06

### Added
- Узнаваемый значок расширения в стиле Win95: жёлтая папка в рамке фокуса, PNG 256 × 256, SVG и генератор без зависимостей.

## 0.2.0 — 2026-10-06

### Added
- Единое расширение: навигатор Explorer Pro и обратимый фокус рабочего пространства FocusedRoot.
- Выбор корня навигатора, домашняя папка, терминал выбранного каталога, история фокуса и индикатор возврата.
- Сохранение фокуса внутри отдельного служебного workspace для восстановления после перезапуска.
- Модульные тесты ошибок восстановления и проверки внутри установленного VS Code.

### Fixed
- Двойной клик обрабатывается командой элемента, а не событием смены выделения.
- Команды возвращают Promise и выполняются последовательно; контекстное меню открывает переданный элемент.
- При отмене переключения или до перезапуска окна сохраняется прежнее состояние фокуса и возврата.
- Повторные переходы не создают одинаковые терминалы и записи истории.
- Сокращение истории сохраняет текущий каталог; повреждённый курсор не ломает восстановление.
- Watcher текущего каталога заменяется с освобождением обработчиков вместо накопления подписок.

### Changed
- Один TreeView вместо TreeView и второго webview-навигатора.
- Автоматическое открытие терминалов выключено по умолчанию.
- Переход в домашнюю папку перемещает навигатор; изменение workspace выполняется отдельной командой.

### Security
- Убран общий cross-window handoff: состояние привязано к конкретному служебному workspace.
- Исходный сохранённый workspace не перезаписывается при фокусе.
- Обновлены сборочные и тестовые зависимости; `npm audit` не обнаруживает уязвимостей.
- Терминалы не запускаются в недоверенном workspace.
