# Changelog

## Unreleased

## 0.6.0 — 2026-10-06

### Added
- Rename файла или папки из контекстного меню и по F2. Штатное переименование VS Code, отмена ввода и защита от перезаписи существующего элемента.

## 0.5.1 — 2026-10-06

### Changed
- Go to Root, Show/Hide Hidden Files и Collapse All перенесены в меню «…» панели.

## 0.5.0 — 2026-10-06

### Added
- Переключатель скрытых файлов и папок (имя начинается с точки) в заголовке панели и палитре команд. Состояние сохраняется в настройках, подпись кнопки отражает следующее действие.

## 0.4.3 — 2026-10-06

### Changed
- Название команды удаления сокращено до Move to Trash в обеих локализациях.

## 0.4.2 — 2026-10-06

### Changed
- Отображаемое название расширения сокращено до Explorer Pro.

## 0.4.1 — 2026-10-06

### Changed
- Значок расширения заменён на современную синюю папку с рамкой фокуса; скругления и сглаживание вместо пиксельного Win95-оформления.

## 0.4.0 — 2026-10-06

### Added
- Удаление выбранных файлов и папок в системную корзину через меню, Delete / Cmd+Backspace.
- Множественное выделение: Shift для диапазона, Cmd/Ctrl для отдельных элементов.
- Подтверждение с путями, защита несохранённых документов, корня навигатора и его родителей, сообщения о частичных ошибках.

### Fixed
- Во время множественного выделения клики не открывают файлы и не переходят внутрь папок.
- При выборе папки и её вложенных элементов удаляется только папка.


## 0.3.0 — 2026-10-06

### Added
- Выбор выхода при недоступном исходном проекте: найти проект, открыть сохранившиеся корни или пустой workspace.
- Индикатор `Фокус: project/backend/api` с меню «Назад», «Полный проект», «Выбрать другой фокус».
- Автоматическая и ручная очистка собственных служебных workspace старше 30 дней с сохранением 20 последних, активных окон и точек возврата.

### Fixed
- Терминал панели открывается в выделенной папке; для выбранного файла используется родительская папка.
- Если shell integration сообщает другую cwd в существующем терминале, создаётся новый терминал в нужной папке, прежний процесс сохраняется.
- Добавлен getParent для корректного выделения элементов TreeView через reveal.


## 0.2.1 — 2026-10-06

### Added
- Узнаваемый значок расширения в стиле Win95: жёлтая папка в рамке фокуса, PNG 256 × 256, SVG и генератор без зависимостей.

## 0.2.0 — 2026-10-06

### Added
- Единое расширение: навигатор Explorer Pro и обратимый фокус рабочего пространства FocusedRoot.
- Выбор корня навигатора, домашняя папка, терминал выбранного каталога, история фокуса и индикатор возврата.
- Сохранение фокуса внутри отдельного служебного workspace для восстановления после перезапуска.
- Модульные тесты ошибок восстановления и проверки внутри установленного VS Code.

### Fixed
- Двойной клик обрабатывается командой элемента, а не событием смены выделения.
- Команды возвращают Promise и выполняются последовательно; контекстное меню открывает переданный элемент.
- При отмене переключения или до перезапуска окна сохраняется прежнее состояние фокуса и возврата.
- Повторные переходы не создают одинаковые терминалы и записи истории.
- Сокращение истории сохраняет текущий каталог; повреждённый курсор не ломает восстановление.
- Watcher текущего каталога заменяется с освобождением обработчиков вместо накопления подписок.

### Changed
- Один TreeView вместо TreeView и второго webview-навигатора.
- Автоматическое открытие терминалов выключено по умолчанию.
- Переход в домашнюю папку перемещает навигатор; изменение workspace выполняется отдельной командой.

### Security
- Убран общий cross-window handoff: состояние привязано к конкретному служебному workspace.
- Исходный сохранённый workspace не перезаписывается при фокусе.
- Обновлены сборочные и тестовые зависимости; `npm audit` не обнаруживает уязвимостей.
- Терминалы не запускаются в недоверенном workspace.
