# ADR 0001: единый навигатор и обратимый фокус

Дата: 2026-10-06. Статус: принято.

## Контекст

Explorer Pro 0.1.1 реализует TreeView и историю каталогов. FocusedRoot 0.2.2 меняет workspace, содержит второй навигатор webview и общий глобальный handoff. При изменении первого корня VS Code перезапускает Extension Host, поэтому сохранение состояния после `updateWorkspaceFolders` ненадёжно. Общий handoff может быть прочитан другим окном.

Исходные каталоги обоих прототипов содержат незакоммиченные изменения. Для объединения создан отдельный `vscode-explorer-pro`; исходники прототипов сохранены. За основу взят текущий TreeView Explorer Pro, включая его незакоммиченные изменения. Поведение FocusedRoot перенесено с переработкой сохранения состояния, без второго webview.

## Решение

Навигация изменяет только TreeView. Фокус выполняется отдельной командой и открывает служебный `.code-workspace` в текущем окне через `vscode.openFolder`. До открытия в файл записываются целевая папка и исходный snapshot с историей. UUID в имени файла различает переходы и окна. После перезапуска состояние загружается только из собственного workspace внутри глобального хранилища и только при совпадении фактического корня.

Для возврата к сохранённому workspace используется исходный URI; одиночная папка открывается непосредственно, несохранённый набор папок — отдельным восстановленным workspace. При ошибке подготовки/открытия состояние возврата не очищается. Чистый `WorkspaceFocus` тестируется через интерфейс `FocusHost`; файловый адаптер и регистрация команд проверяются в реальном VS Code.

## Последствия

Исходный workspace не изменяется, состояние не переносится через общий handoff. Переключение может перезапустить расширения. Настройки, tasks и launch уровня исходного workspace в фокус не копируются; исходные параметры возвращаются при открытии первоначального файла. Служебные файлы пока сохраняются для восстановления. Поддержка ограничена локальными каталогами.

Источники: [VS Code workspace API](https://code.visualstudio.com/api/references/vscode-api#workspace), [официальная проверка расширений](https://code.visualstudio.com/api/working-with-extensions/testing-extension).

## Дополнение 0.3.0

При недоступном источнике возврата пользователь выбирает восстановление сохранившихся корней, новый адрес проекта или пустой workspace. Отмена не изменяет состояние. Очистка использует маркер собственных файлов, временные lease-записи живых Extension Host процессов, сохранение последних 20 файлов и рекурсивную защиту original.workspaceFile. Удаляются только незащищённые собственные файлы старше 30 дней.
